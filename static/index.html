Implementation notes

  • Double-entry invariant: every transaction creates 2 balanced lines (debit = credit). Trial balance is checked after each ingestion.
  • Categorization: heuristic model with confidence and reasoning; low-confidence rows flagged needs review instead of auto-posted.
  • Fuzzy dedupe: flags same amount ±3 days + 82% description similarity for review.
  • Review queue: rejected rows persist to DB, not logs. Resolve or dismiss in the UI.
